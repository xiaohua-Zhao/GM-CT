# 登录认证运维说明

## 1. 接口

```text
POST /api/auth/login    登录
GET  /api/auth/me       当前用户
POST /api/auth/logout   退出登录
```

## 2. 环境变量

```text
JWT_SECRET=至少32位随机字符串
JWT_EXPIRATION_SECONDS=28800
JWT_ISSUER=chengtai-fashion-mgmt
AUTH_LOGIN_LOG_ENABLED=true
AUTH_ACCESS_LOG_ENABLED=false
AUTH_TOKEN_DEBUG_ENABLED=true
AUTH_LOG_RETENTION_DAYS=90
AUTH_LOG_CLEANUP_CRON=0 0 3 * * ?
```

## 3. 日志位置

```text
认证日志：logs/auth/chengtai-auth.log
主日志：logs/chengtai-fashion-mgmt.log
历史认证日志：logs/auth/chengtai-auth.yyyy-MM-dd.i.log.gz
```

## 4. TraceId

每个请求都会生成 `X-Request-Id`，同时写入响应头、认证日志和登录日志表。
用户反馈登录问题时，优先获取响应头中的 `X-Request-Id`。

## 5. 常用错误码

| 错误码 | 含义 |
|---|---|
| AUTH_ACCOUNT_NOT_FOUND | 登录账号不存在 |
| AUTH_PASSWORD_MISMATCH | 密码错误 |
| AUTH_PASSWORD_NOT_SET | 未设置密码 |
| AUTH_ACCOUNT_DISABLED | 账号停用或离职 |
| AUTH_TOKEN_MISSING | 未携带 Token |
| AUTH_TOKEN_EXPIRED | Token 过期 |
| AUTH_TOKEN_INVALID | Token 非法 |
| AUTH_ACCOUNT_DISABLED_AFTER_LOGIN | 登录后账号被停用 |

## 6. 登录日志查询

```sql
SELECT login_log_id, trace_id, staff_code, login_name, login_status,
       failure_code, ip_address, client_type, cost_ms, token_expire_at, created_at
FROM ct_gm.t_sys_login_log
ORDER BY login_log_id DESC
LIMIT 100;
```

## 7. 日志查看

```powershell
Get-Content 'D:\DevelopSoftware\code\coding\code\GM-CT\logs\auth\chengtai-auth.log' -Encoding UTF8 -Wait -Tail 100
```

## 8. 清理策略

- 登录日志表默认保留 90 天
- 每天凌晨 3 点执行清理
- 认证文件日志滚动保留 30 天
- 单个日志文件最大 50MB，总容量上限 5GB
